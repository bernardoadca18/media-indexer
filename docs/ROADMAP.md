# Roadmap

## Implemented

Stage 1 foundation, Stage 2 local ingestion/ffprobe, and deterministic Stage 3
note parsing.

## Planned

1. Timestamped local ASR with persisted segments.
2. Scene changes, representative frames and derived assets.
3. Searchable temporal segments, then embeddings and pgvector.
4. Candidate retrieval for notes and footage.
5. Provider-neutral multimodal alignment where unmatched is valid.
6. Semantic Timeline export and project/session Media Search.

Editorial work stays in Ideas Hub; voice, planning, composition and rendering
stay in production services.
